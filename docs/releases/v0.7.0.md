# Where 0.7.0 — governance, CI hardening and macOS licence fix

**Find what you're looking for.** Where connects your projects, tasks, notes,
saved links and files in one private, offline search.

This release adds the `GOVERNANCE.md` file referenced by the project's open-source
licence decision, fixes an incorrect copyright string in the macOS build, and pins
all CI jobs to Ubuntu 24.04 ahead of GitHub's move to Ubuntu 26 in October 2026.

## What's new

### GOVERNANCE.md
The project now has a `GOVERNANCE.md` that documents the maintainer structure,
how contributions are licensed (Apache 2.0, inbound = outbound, no CLA required),
the ADR policy and the release process. This was referenced by the Apache 2.0
licence decision but was never committed.

### macOS copyright string fixed
The macOS app's copyright field in `AppInfo.xcconfig` previously read
*"All rights reserved."*, which was inconsistent with the Apache 2.0 licence.
It now reads *"Licensed under the Apache License, Version 2.0."*

### CI runners pinned to Ubuntu 24.04
All GitHub Actions jobs that used `ubuntu-latest` are now pinned to `ubuntu-24.04`.
GitHub is moving `ubuntu-latest` to Ubuntu 26 in October 2026; this pin prevents
a surprise CI failure before the transition is tested.

## First launch

These builds aren't code-signed yet:
- **Windows:** *Windows protected your PC* → **More info → Run anyway**.
- **Mac:** right-click Where → **Open** → **Open**.
- **Linux AppImage:** `chmod +x` first. On Ubuntu 22.04+ you may need `sudo apt install libfuse2`.
